
# Python Data Analysis Project

## About the Project
This project is a basic data analysis project using Python. It focuses on working with data, analyzing it and creating visualizations to understand the results.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Excel

## Project Work
- Loaded and worked with data using Pandas
- Performed basic data analysis
- Calculated and compared values
- Analyzed data region-wise
- Created graphs and visualizations using Matplotlib

## Files Included
- `project.py` – Python code used for the analysis
- `Data.xlsx` – Dataset used in the project
- `Project.docx` – Project documentation

## Skills Practiced
- Data handling with Pandas
- Basic data analysis
- Data visualization
- Working with Excel data
